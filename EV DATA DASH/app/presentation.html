Data Engineering
Alteryx ETL Data Cleansing & Transformation
Workflow Pipeline Modules
  • Input & Select Tool: Ingests raw telemetry and formats field datatypes.
  • Data Cleansing: Strips whitespace, null padding, and malformed telemetry.
  • Imputation Engine: Fills missing ambient temperatures using median depot values.
  • Unique & Filter: Deduplicates on composite key (Vehicle_ID, Charging_Start_Time).
Feature Engineering & Metrics
  • Energy Efficiency: Calculates (Energy_Consumed / Distance) * 100 (kWh/100km).
  • SOH Degradation Bucket: Categorizes battery health (Optimal > 90%, Moderate 80-90%, Alert < 80%).
  • Cost Tariff Engine: Maps charging session timestamp against peak/off-peak grid rates.
  • Cleaned CSV landing export for Snowflake stage.
💡 Speaker Notes: Alteryx handles raw data quality before warehousing. It resolves missing sensor telemetry, deduplicates records, and calculates custom features like SOH degradation risk buckets.
Cloud Data Warehousing
Snowflake Star Schema & CDC Tasks
Multi-Tier Schema DDL
  • RAW Schema: Staging tables for raw CSV copy loads.
  • CORE Schema: Star Schema dimension & fact tables:
    • DIM_VEHICLE: Vehicle model, battery size, depot ID.
    • FACT_CHARGING_SESSIONS: SOH, kWh, cost, efficiency.
  • MART Schema: Pre-aggregated analytical business views.
Stored Procedures & CDC
  • SP_POPULATE_STAR_SCHEMA(): Transforms RAW into CORE dimensional model.
  • SP_CALCULATE_BATTERY_DEGRADATION(): Tracks monthly SOH decay per vehicle model.
  • CDC Streams: Captures change data on staging tables.
  • Scheduled Tasks: Triggers warehouse refresh every 60 minutes automatically.
💡 Speaker Notes: Snowflake is configured with a high-performance Star Schema model. Change Data Capture (CDC) streams and 60-minute automated tasks ensure data is always fresh.
Process Orchestration
UiPath Robotic Process Automation (RPA)
Automated Workflow Orchestration
  • File System Watcher: Automatically detects cleaned CSV drops from Alteryx.
  • Snowflake DB Connector: Triggers SP_POPULATE_STAR_SCHEMA execution.
  • Power BI REST API: Invokes automated dataset refresh upon SP completion.
  • Exception Handling: Try-Catch blocks log any network or payload errors.
Executive Reports & Alerts
  • Daily Excel Generator: Builds executive fleet summary spreadsheets.
  • HTML Email Dispatcher: Distributes daily reports to executive leadership.
  • Alert System: Immediately emails fleet engineers if vehicle SOH < 80%.
  • Audit metrics recorded to GOVERNANCE.AUDIT_LOGS.
💡 Speaker Notes: UiPath RPA connects the entire enterprise loop. It detects files, runs database jobs, refreshes BI reports, and dispatches critical alerts to managers.

Security & Governance
Data Governance, Security & Lineage
Security & RBAC Framework
  • Role-Based Access: EV_ADMIN, EV_DATA_ENGINEER, EV_ANALYST, EV_MAINTENANCE_TECH.
  • Column-Level Masking: Redacts driver PII & exact location coordinates for analyst roles.
  • Encryption: AES-256 at rest, TLS 1.3 in transit across all endpoints.
  • Time Travel & DR: 30-day Snowflake Time Travel and multi-region backup.
Quality Matrix & Lineage
  • Data Quality Rules: Traps invalid SOH (<50% or >100%) and routes to GOVERNANCE.DATA_QUALITY_EXCEPTIONS.
  • Audit Logging: Logs every transaction, procedure run, and RPA step.
  • End-to-End Lineage: Documented lineage from raw telemetry CSV to executive dashboard.
💡 Speaker Notes: Enterprise security is enforced via granular RBAC roles, column masking for privacy compliance, automated exception logging, and full auditability.
